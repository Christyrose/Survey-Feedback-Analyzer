# Survey-Feedback-Analyzer

## Project Overview

The Survey Feedback Analyzer is a Python project that analyzes survey feedback using basic Python programming concepts.

The project stores feedback data in a dictionary of lists, allows users to add new feedback, cleans the feedback text, and extracts information from the responses.

## Objectives

- Store survey feedback using a dictionary of lists
- Add additional feedback from the user
- Clean feedback text
- Count feedbacks containing specific words
- Calculate the average rating
- Find the feedback with the longest comment
- Identify unique words used in the feedback

## Project Steps

### Step 1: Preloaded Feedbacks
The project starts with 10 predefined survey feedback entries containing:

- Serial Number
- Name
- Feedback
- Rating

### Step 2: Add More Feedbacks
Users can enter additional feedbacks, including the name, written feedback, and rating.

### Step 3: Text Cleaning
The feedback is cleaned by:

- Removing punctuation
- Removing extra spaces
- Removing leading and trailing spaces
- Converting text to lowercase

### Step 4: Word Count Insights
A function is used to count how many feedbacks contain specific words such as:

- `good`
- `poor`
- `excellent`

### Step 5: Final Summary
The project displays:

- Final cleaned feedback data
- Average rating
- Longest feedback
- Unique words
